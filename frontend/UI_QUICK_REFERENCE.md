# UI Quick Reference Card 🎨

## Keyboard Shortcuts ⌨️

| Shortcut | Action | Where |
|----------|--------|-------|
| `Cmd/Ctrl + N` | Create New | Collections or Documents |
| `Cmd/Ctrl + F` | Search | Documents page |
| `Escape` | Close Dialog | Any open dialog |

---

## Dark Mode 🌙

**Toggle:** Click the sun/moon icon in the top-right corner

**Light Mode:**
- Bright, clean interface
- White backgrounds
- Blue accents

**Dark Mode:**
- Easy on the eyes
- Dark backgrounds
- Lighter blue accents
- Perfect for night work

---

## File Upload 📤

### Method 1: Drag & Drop (Recommended)
1. Click "Add Document"
2. Switch to "File Upload" tab
3. **Drag your file** into the blue zone
4. See instant preview

### Method 2: Browse
1. Click "Add Document"  
2. Switch to "File Upload" tab
3. Click the upload zone
4. Select your file

**Supported:** PDF, DOCX, TXT, JSON

---

## Search Documents 🔍

### Quick Search
1. Type in the search bar
2. Results filter instantly
3. See match count below

### Advanced
- Searches: name, purpose, tags, content
- Clear with X button
- Shortcut: `Cmd/Ctrl + F`

---

## Toast Notifications 🎉

Notifications appear in the **top-right corner**:

- 🟢 **Green:** Success
- 🔴 **Red:** Error
- 🟠 **Orange:** Warning
- 🔵 **Blue:** Info

Auto-dismiss after 3-5 seconds

---

## Tips & Tricks 💡

### Fast Document Upload
1. Press `Cmd/Ctrl + N`
2. Switch to File Upload tab
3. Drag file
4. Press Enter

### Quick Search
1. Press `Cmd/Ctrl + F`
2. Type query
3. Hit Escape to exit

### Close Dialogs Fast
Press `Escape` to close any open dialog

## Chunk Size Presets 📏

- **Small (200-300):** Definitions, short entries
- **Medium (500):** Default, general use
- **Large (800-1000):** Policies, long documents

## Status Indicators ⚡

**Processing:**
- Blue info notification

- Auto-refresh on completion

**Success:**
- Green toast notification

**Error:**

## Best Practices ✨

### Document Names
- Use descriptive names
- Include version if applicable
- Example: "Employee Handbook v2.1"

### Tags
- Use comma-separated values
- Keep tags short
- Example: "hr, policy, 2024"

### Chunk Sizes
- Larger for detailed docs
- Smaller for quick refs
- Test and adjust

---

## Troubleshooting 🔧

### Can't Find Document?
- Try different search terms
- Check spelling
- Look in correct collection

### Upload Failed?
- Check file format (PDF, DOCX, TXT, JSON)
- Verify file size
- Check network connection

### Dark Mode Issues?
- Refresh page
- Clear browser cache
- Check localStorage
